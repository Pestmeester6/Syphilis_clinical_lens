# Syphilis Through the Clinical Lens

Participant resources for the PAHO and LSHTM webinar series, September–October 2026.

Five sessions with faculty, topics, objectives, publications, summaries and recordings. Includes course materials and clinical app links.

Open index.html with assets alongside it. No build required. To host using GitHub Pages, publish main from the repository root.

Recording access depends on the supplied Zoom settings. Session 4 uses neutral attribution because the source summary had inconsistent speaker attribution.

## Export to PDF

Use the **PDF layout** selector at the top of the webpage, then **Print or save as PDF**.

- **One page per session**: eight pages in total, including the introduction and two resource pages.
- **Two pages per session**: thirteen pages in total with larger body type; summary and recording access start on the second page of each session.

In the browser print dialog choose Save as PDF, A4 portrait, 100% scale, background graphics on, and browser headers/footers off. All publication and recording hyperlinks remain clickable in the PDF. Faculty portraits remain with the relevant session; the repeated faculty directory and live navigation controls are omitted from print.

The print CSS was rendered and reviewed in both modes using WeasyPrint. Browser print engines can differ slightly.

## Resource order

The original four resources are retained. The section starts with the PAHO congenital syphilis course, shared webinar materials, PAHO's 15 recommendations, and PAHO elimination guidance. Other dated publications follow newest to oldest; clinical tools remain at the end. All 11 guidance documents include official publisher covers or first-page images, embedded as compact thumbnails so PDF export does not depend on third-party image requests.
